# Olympic-Analysis

This is a data analysis web application built using Python and Streamlit. It provides an interactive interface to explore over 120 years of historical Olympic data (Summer Games).

The app allows users to visualize medal tallies, analyze country-wise performance, and explore athlete demographics (age, height, weight) through dynamic plots and heatmaps.

Key Features
The application is divided into four main sections:

1. Medal Tally
View global medal standings.

Filter tallies by Year and Country.

See the total count of Gold, Silver, and Bronze medals.

2. Overall Analysis
Top Statistics: Total editions, host cities, sports, events, nations, and athletes.

Trends: Visualizations of participating nations and events over time.

Heatmap: Activity heatmap showing the number of events for every sport over the years.

3. Country-wise Analysis
Medal Heatmap: Visualizes a specific country's medal performance across different sports and years.

Top Athletes: Lists the most successful athletes (Top 10) for any selected country.

4. Athlete-wise Analysis
Age Distribution: Probability density curves showing the age distribution of all athletes vs. Gold Medalists.

Physical Attributes: Scatter plots analyzing the relationship between Height and Weight for medalists in different sports.

Gender Participation: A line chart tracking the participation of Men vs. Women over the years.
